# 本地可重建产物

`Artifacts` 只用于可重建的构建、打包、发布和验证输出，不是源码目录，也不是长期审查证据目录。各子目录必须明确属于以下一种策略：

- 可重建产物：加入 `.gitignore`，由构建或验证命令重新生成。
- 发布制品：由 CI 制品库或镜像仓库保存，Git 只保留 manifest 和校验信息。
- 验证输出：只保留本次运行需要的临时报告；需要关联需求、工单或审批记录时迁入 `Evidence`。

当前 `LinuxServer` 和 `WorkflowC` 属于可重建产物。`MonitoringWorkflowA` 是历史兼容目录，新增长期证据不得继续写入该目录。未经专项迁移审查，不得批量删除其他子目录。
