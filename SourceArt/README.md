# 美术源资产治理

`SourceArt` 保存可追溯的 Blender、纹理、音频、UI 原图和中间制作文件；Unreal 可发布资产位于 `Content`。源文件、导出文件和引擎资产不得混为同一事实来源。

## 推荐结构

每个资产族逐步采用以下分层：

```text
<AssetFamily>/
├─ Source/       # DCC 原始文件及外部依赖
├─ Export/       # FBX、glTF、WAV、PNG 等确定性导出
├─ Preview/      # 人工审查截图或转台预览
├─ manifest.json # 源文件、工具版本、比例、坐标系、导出参数和目标 Content 路径
└─ LICENSE.md    # 自制/授权来源及使用限制
```

## 更新规则

- 更新模型、材质或贴图时，先在本次任务范围内精确删除旧目标资产及明确废弃依赖，再全量生成或导入。
- 不依赖覆盖导入或 Reimport 保留旧设置；无关资产不得删除。
- `.uasset/.umap` 的移动、重命名和引用修复必须在 Unreal Editor 内完成。
- manifest 至少记录厘米制比例、坐标系、法线/切线策略、LOD、碰撞、纹理色彩空间、PBR 通道和导入目标。
- 人工审查截图必须按目标应用窗口真实边界截取，多窗口分别命名。
